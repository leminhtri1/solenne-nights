SOLENNE NIGHTS is an original open-world crime game in three.js: steal any car, bike or boat in the sun-soaked bay city of Solenne, outrun a five-star police response with roadblocks and a searchlight helicopter, and play nine story chapters against the developer Victor Kessane, from golden hour to neon night. Everything (city, cars, people, music, sound) is generated in code and runs from static files.

## Run it

```sh
node serve.ts   # then open http://localhost:8080
```
